# Подключение заявок сайта к Google Таблицам

Форма на сайте подготовлена для передачи заявок через Google Apps Script. Автоматическая запись начнёт работать только после создания таблицы, публикации скрипта и указания URL веб-приложения в коде сайта.

## 1. Создайте отдельную таблицу

Создайте новую Google Таблицу с названием, например, «Вектор Сервис — заявки с сайта». Не используйте личную таблицу с посторонними данными. Ограничьте доступ к ней только сотрудникам, которым действительно нужно обрабатывать обращения.

Скопируйте ID таблицы из адреса:

`https://docs.google.com/spreadsheets/d/ВАШ_ID_ТАБЛИЦЫ/edit`

## 2. Подготовьте Apps Script

1. В таблице откройте **Расширения → Apps Script**.
2. Замените содержимое файла `Code.gs` кодом из папки `google-apps-script` этого репозитория.
3. В строке `SPREADSHEET_ID` укажите ID созданной таблицы.
4. Сохраните проект.

Скрипт создаёт лист «Заявки с сайта» и строку заголовков при первом обращении.

## 3. Опубликуйте веб-приложение

1. Нажмите **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: владелец скрипта.
4. Доступ: выберите вариант, который разрешён политиками аккаунта и согласован с ответственным за персональные данные.
5. Разверните приложение и скопируйте URL веб-приложения, заканчивающийся на `/exec`.

Не публикуйте URL таблицы и не предоставляйте посетителям доступ к самой таблице.

## 4. Подключите URL к сайту

В `index.html` найдите:

```js
const GOOGLE_APPS_SCRIPT_URL = '';
```

Вставьте URL веб-приложения между кавычками. Сохраните файл и опубликуйте изменения после проверки.

## 5. Проверьте работу

Отправьте тестовую заявку со своим тестовым номером. Убедитесь, что в таблице появилась одна строка с датой, именем, телефоном, выбранным направлением, комментарием, отметкой согласия и источником.

Проверьте также:
- пустые имя и телефон не отправляются;
- без согласия заявка не отправляется;
- поле-ловушка для ботов не отображается обычному посетителю;
- после успешной записи форма показывает подтверждение;
- при ошибке пользователь видит телефон компании для связи.

## Важные замечания по персональным данным

Форма намеренно собирает минимум сведений. Не просите посетителя указывать в открытом поле номера воинских частей, точные координаты, сведения о перемещениях военнослужащих, паспортные данные, подробности состояния здоровья или прикладывать документы.

Перед реальным запуском необходимо проверить с ответственным за персональные данные и юристом компании:
- допустимость использования Google Таблиц для хранения заявок с учётом требований российского законодательства о персональных данных и локализации баз данных;
- правовое основание, текст и способ фиксации согласия;
- актуальность политики обработки персональных данных, сроки хранения и порядок удаления заявок;
- кто из сотрудников имеет доступ к таблице и как защищён аккаунт владельца.

Если использование Google Sheets не соответствует требованиям компании или применимым требованиям законодательства, этот способ нельзя включать в эксплуатацию. Потребуется российская система хранения заявок или CRM с подходящей инфраструктурой.

**Сейчас интеграция в коде подготовлена, но не активирована:** для активации нужны таблица и URL опубликованного Apps Script Web App.
